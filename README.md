# Oslo – Lindesnes – Nordkapp by bike

A 39-stage, 3,590 km cycling route through Norway, with landmarks, detours and backup cabins.

- **Map:** open `kart.html` (or the GitHub Pages site for this repo).
- **Plan:** [RUTE.md](RUTE.md)
- **GPX:** [oslo-lindesnes-nordkapp.gpx](oslo-lindesnes-nordkapp.gpx) and one file per stage in [stages/](stages/)
