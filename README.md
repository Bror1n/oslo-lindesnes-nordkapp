# Oslo – Lindesnes – Nordkapp by bike

A 39-stage, 3,590 km cycling route through Norway, with landmarks, detours and backup cabins.

- **Map:** open `kart.html` (or the GitHub Pages site for this repo).
- **Plan:** [RUTE.md](RUTE.md)
- **GPX:** [oslo-lindesnes-nordkapp.gpx](oslo-lindesnes-nordkapp.gpx) and one file per stage in [stages/](stages/)
- **Gravel mode:** a switch that moves the route onto gravel roads where that makes sense, 449 km of gravel instead of 272 km. It combines with the alternatives, which each have a gravel version. GPX in [variants/gravel.gpx](variants/gravel.gpx)
- **Alternatives:** five selectable variants (the whole coast to Trondheim, Lysefjord, Nigardsbreen, Geiranger and the Atlantic Road, Havøysund), switchable on the map, GPX in [variants/](variants/)

Route data © OpenStreetMap contributors, routed with BRouter. Map tiles © Kartverket.
